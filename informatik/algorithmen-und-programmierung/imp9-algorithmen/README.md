# IMP Klasse 9 – Algorithmen (Processing)

Unterrichtseinheit *Algorithmen* (Bildungsplan IMP 3.2.1.2) für Klasse 9 mit Processing.

Themen: Wiederholung der Kontrollstrukturen, Methoden zum Zeichnen, Zählschleife, optische Täuschungen (Kaffeehaus-Täuschung, Hermann-Gitter, Wellen), Balkendiagramme, Zufallszahlen, externe Daten (CSV), Maximumsuche, weitere Array-Algorithmen und xy-Diagramme.

| Ordner | Inhalt |
|---|---|
| `01_hintergrund/` | Stoffverteilungsplan, Unterrichtsverlauf |
| `02_kopiervorlagen/` | Arbeitsblätter (PDF) |
| `03_vorlagen_tauschordner/` | Processing-Vorlagen für Schülerinnen und Schüler |
| `04_loesungen/` | Lösungen (Processing) |
| `IMP_9_alle_Arbeitsblaetter.pdf` | Alle Arbeitsblätter in einer Datei |

Passend dazu gibt es das interaktive [for-Schleifen-Puzzle](../for-schleifen-puzzle/).

## Quellen und Lizenz

Das Material basiert auf den Unterrichtsmaterialien zu IMP der Lehrerfortbildung Baden-Württemberg (u. a. Eisenmann, Schaller) und steht unter einer Creative-Commons-Lizenz. Es wurde für den eigenen Unterricht angepasst und ergänzt.
