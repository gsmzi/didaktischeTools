# Mehrbit-Addierer (Ripple-Carry-Addierer) mit Überlauf

Visualisiert die Addition mehrstelliger Binärzahlen mit einer Kette von Volladdierern.

- Schriftliche Bitrechnung mit Überträgen
- Addierer-Kette mit Übertragsweitergabe
- Erkennen von Überlauf
- Aufgabenmodus zum Üben

**Einsatz:** [index.html](index.html) im Browser öffnen, keine Installation nötig.
