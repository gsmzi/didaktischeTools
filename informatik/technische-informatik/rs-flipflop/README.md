# RS-Flipflop – Interaktive Visualisierung

Speicherverhalten eines RS-Flipflops als einfachstes Schaltwerk.

- Eingänge und Ausgänge interaktiv schalten
- Gatter-Schaltung mit Signalfluss
- Signal-Verlauf (Timing-Diagramm)
- Arbeitsblatt-Tabelle zum Ausfüllen
- Hintergrund zu weiteren Flipflop-Typen

**Einsatz:** [index.html](index.html) im Browser öffnen, keine Installation nötig.
