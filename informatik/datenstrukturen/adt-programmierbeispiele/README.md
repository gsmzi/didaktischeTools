# ADT-Programmierbeispiele (Processing)

Programmierprojekte zu abstrakten Datentypen in [Processing](https://processing.org).
In `vorlagen/` stehen die Schülervorlagen mit TODOs, in `loesungen/` die vollständigen Lösungen.

| Projekt | Thema |
|---|---|
| p02_verkettete_liste | Verkettete Liste (iterativ / rekursiv) |
| p03_listenvarianten_benchmark | Listenvarianten im Vergleich, Sortierverfahren mit Laufzeitmessung |
| p04_set | ADT Set (Menge), verschiedene Implementierungen |
| p05_stack | ADT Stack (Array, verkettet, Cantor-Paarung) |
| p06_hanoi, p06_freecell | Anwendungen des Stacks |
| p07_queue | ADT Queue |
| p08_snake | Anwendung der Queue: Snake |
| p09_entscheidungsbaum | Binärbaum: Entscheidungsbaum |
| p10_baumalgorithmen, p10_terme | Baumalgorithmen, Termbäume |
| p11_hanoi_automatisch | Türme von Hanoi automatisch lösen |
| p12_tiefen_und_breitensuche, p12_tiefer_baum | Tiefen- und Breitensuche |
| p13_sudoku | Sudoku-Löser |

**Einsatz:** Den Projektordner in Processing öffnen. Die Hauptdatei heißt wie der Ordner.

## Quellen

Die Projekte sind Processing-Portierungen der Java-Materialien zu ADTs von Rainer Helfrich (ZSL Baden-Württemberg, Lehrerfortbildung Informatik).
