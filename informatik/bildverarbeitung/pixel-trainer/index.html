IMP 10 · Bilder als zweidimensionale Arrays: Spiegeln, Drehen, Farben, Graustufen

Begriffe

Bildarray: color[][] pixel; pixel[x][y] ist das Pixel in Spalte x und Zeile y. Die Zählung beginnt oben links bei (0|0).

Breite und Höhe: pixel.length ist die Breite (Anzahl der Spalten), pixel[0].length die Höhe. Der größte Index ist jeweils Breite − 1 bzw. Höhe − 1.

Ergebnisarray: Jede Methode legt ein neues Array pixelNeu an und liest nur aus pixelAlt. Das Original bleibt unverändert.

Verschachtelte Zählschleife: Die äußere Schleife läuft über die Spalten (x), die innere über die Zeilen (y) – so wird jedes Pixel des neuen Bildes genau einmal gesetzt.

ArrayIndexOutOfBoundsException: Fehler, wenn ein Index kleiner als 0 oder zu groß ist, z. B. pixelAlt[breite][0].

RGB: Jede Farbe besteht aus Rot-, Grün- und Blauanteil (je 0–255). red(farbe), green(farbe), blue(farbe) lesen die Anteile; color(m) ist ein Grauton.

Hexcode: #RRGGBB, je zwei Hexadezimalziffern pro Anteil (FF = 255, 80 = 128).

Kappen: Werte über 255 werden auf 255 gesetzt, Werte unter 0 auf 0.

Hinweis: Damit eine Methode in Processing wirklich ausgeführt wird, muss sie in setup() aufgerufen werden, z. B. color[][] pixelNeu = spiegleHorizontal(pixelAlt);
