# Zweierkomplement – Interaktive Visualisierung

Darstellung negativer ganzer Zahlen im Zweierkomplement.

- Eingabe einer Zahl und Interpretation des Bitmusters (vorzeichenlos / vorzeichenbehaftet)
- Negation Schritt für Schritt (invertieren, +1)
- Probe: Zahl + Gegenzahl = 0
- Zahlenkreis und Wertetabelle
- Aufgabenmodus zum Üben

**Einsatz:** [index.html](index.html) im Browser öffnen, keine Installation nötig.
