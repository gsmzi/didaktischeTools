# Metadaten-Detektiv

Zusatzaufgabe für Schnelle zur Simulation [Wer liest mit?](../wer-liest-mit/), IuM Klasse 7 (Bildungsplan 3.2.4.1, Teilkompetenz 2).

Vier Freunde nutzen einen Messenger mit Ende-zu-Ende-Verschlüsselung. Die Schülerinnen und Schüler sind der Server: Sie sehen eine Woche lang nur die Metadaten (wer, wann, an wen, Art, Größe) und erschließen daraus Schlafenszeiten, die große Pause, einen Streit, ein Treffen und einen Arzttermin.

- **Server-Protokoll** mit Filter nach Person, Tag und Art; Inhalte bleiben verschlüsselt
- **Kontaktnetz**, Woche oder Tag für Tag: Wo bricht ein Kontakt ab?
- **Tagesrhythmus** je Person als Raster aus Wochentagen und Stunden
- **Ermittlung:** sechs Fragen mit Rückmeldung, welche Spur zur Antwort führt; danach ein Merksatz
- Detektiv-Notizen für eigene Vermutungen

Kernaussage: Ende-zu-Ende-Verschlüsselung schützt den Inhalt, nicht die Metadaten. Metadaten liefern Hinweise, keine Beweise.

Im Ordner [material/](material/) liegt eine Papierfassung mit nummeriertem Protokoll (DOCX und PDF). Die Lösung liegt nicht im Repository.

**Einsatz:** [index.html](index.html) im Browser öffnen, keine Installation nötig, etwa 15–20 Minuten. Alle Personen und Daten sind erfunden.
