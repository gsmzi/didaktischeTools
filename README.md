# didaktischeTools → Lernwerkzeuge

Dieses Repository ist nur eine **Weiterleitung**. Die Tools liegen jetzt unter
<https://gsmzi.github.io/lernwerkzeuge/> (Quellcode: <https://github.com/gsmzi/lernwerkzeuge>).

- `404.html` und `index.html` leiten jede alte Adresse `gsmzi.github.io/didaktischeTools/<pfad>` auf `gsmzi.github.io/lernwerkzeuge/<pfad>` um. Damit funktionieren alte Links, Lesezeichen und gedruckte QR-Codes weiter.
- `aes/pruefungsvorbereitung/aes-pruefungstrainer/sw.js` meldet den Service Worker des installierten AES-Prüfungstrainers an der alten Adresse ab.

**Nicht löschen, nicht umbenennen und GitHub Pages nicht abschalten** – sonst sind alle alten Links tot.
